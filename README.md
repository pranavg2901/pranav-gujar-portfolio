## Running locally

Clone the repo and serve the folder:

```bash
git clone https://github.com/pranavg2901/pranav-gujar-portfolio.git
cd pranav-gujar-portfolio
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Deployment

Intended to be hosted on **GitHub Pages**, served from the `main` branch.
Pages is not enabled on the repository yet — it needs turning on under
**Settings → Pages** before the site goes live.
